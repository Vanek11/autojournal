# AutoJournal

AutoJournal — учебный веб-проект электронного журнала автомобиля.

Проект предназначен для хранения информации об автомобилях, ведения истории обслуживания, учета расходов, загрузки документов и чеков, создания напоминаний, просмотра аналитики и формирования отчета по автомобилю.

Изначально идея проекта была ориентирована на Android-приложение, но в рамках реализации проект выполнен как веб-сайт.

## Функции проекта

### Пользователи

- Регистрация пользователя.
- Авторизация пользователя.
- Выход из аккаунта.
- Изменение имени пользователя.
- Изменение пароля.
- Разделение данных между пользователями.

### Автомобили

- Добавление автомобиля.
- Просмотр списка автомобилей.
- Просмотр карточки автомобиля.
- Редактирование автомобиля.
- Удаление автомобиля.
- Поддержка нескольких автомобилей у одного пользователя.

### Журнал обслуживания

- Добавление записей по автомобилю.
- Типы записей:
  - ТО;
  - ремонт;
  - заправка;
  - расход;
  - документ;
  - другое.
- Учет даты, пробега, суммы, сервиса и комментария.
- Автоматическое обновление текущего пробега автомобиля при добавлении записи с большим пробегом.
- Удаление записей.

### Документы и чеки

- Загрузка файлов:
  - JPG;
  - PNG;
  - WEBP;
  - PDF.
- Добавление внешней ссылки на документ.
- Типы документов:
  - чек;
  - страховка;
  - акт сервиса;
  - фото;
  - PDF;
  - другое.
- Просмотр документов.
- Удаление документов.

### Напоминания

- Создание напоминаний по дате.
- Создание напоминаний по пробегу.
- Создание напоминаний одновременно по дате и пробегу.
- Статусы:
  - активно;
  - скоро;
  - просрочено;
  - пора по пробегу;
  - выполнено;
  - отменено.
- Отметка напоминания как выполненного.
- Возврат напоминания в активное состояние.
- Удаление напоминания.

### Аналитика

- Общая сумма расходов.
- Количество платных записей.
- Средний расход.
- Текущий пробег.
- Расходы по месяцам.
- Расходы по типам.
- Список крупных расходов.

### Отчет

- Формирование отчета по автомобилю.
- В отчете отображаются:
  - основные данные автомобиля;
  - финансовая сводка;
  - история обслуживания и расходов;
  - документы;
  - напоминания;
  - блок подтверждения.
- Печать отчета через браузер.
- Экспорт данных в JSON.
- Экспорт журнала в CSV.

### Команда

- Добавление пользователя в команду по email.
- Роли:
  - просмотр;
  - редактор.
- Просмотр участников команды.
- Удаление участника команды.
- Демонстрация многопользовательского режима.

### Тарифы и платежи

- Страница управления тарифом.
- Тарифы:
  - Free;
  - Standard;
  - Premium.
- Имитация оплаты.
- Сохранение выбранного тарифа в базе данных.
- Сохранение подписки пользователя.

### Дашборд

- Количество автомобилей.
- Расходы за текущий месяц.
- Количество активных напоминаний.
- Количество документов.
- Последние записи журнала.
- Ближайшие напоминания.
- Сводка по автомобилям.
- Быстрые переходы в основные разделы.

## Архитектура

Проект реализован как fullstack-приложение на Next.js.

Frontend находится в компонентах React и страницах App Router.

Backend реализован через API Routes внутри Next.js.

База данных MySQL подключается через Prisma ORM.

Файлы документов в учебной версии сохраняются локально в папку:

```text
public/uploads
```
